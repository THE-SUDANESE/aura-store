# إضافة منتجات إلى متجر AURA

كل منتج يتكوّن من ثلاثة صفوف في قاعدة البيانات:

| الجدول | ماذا يمثّل |
| --- | --- |
| `products` | المنتج نفسه: الاسم، الوصف، السعر الأساسي، الحالة |
| `product_variants` | المتغيرات (لون العدسة/الإطار/المقاس) — **المخزون هنا** |
| `product_images` | روابط الصور، واحدة منها `is_primary` |

نقطة البيع للسلة والطلب تعمل على `product_variants.id` وليس على المنتج،
لذلك أي منتج بلا متغير واحد على الأقل لن يظهر زر «إضافة للسلة» فيه.

---

## 1) الطريقة الموصى بها: تعديل CSV ثم استيراد

المصدر الوحيد للحقيقة هو [docs/products-import.csv](products-import.csv).

```bash
# 1. عدّل الأسماء والأسعار والمخزون في Excel أو أي محرر CSV
#    (احفظ الملف بترميز UTF-8 حتى لا تفسد العربية)

# 2. معاينة ما سيحدث دون كتابة
python scripts/import_products.py --dry-run

# 3. التنفيذ الفعلي على قاعدة البيانات
python scripts/import_products.py
```

الأعمدة:

| العمود | إلزامي | ملاحظات |
| --- | --- | --- |
| `slug` | ✔ | معرّف المنتج في الرابط: `/product/aura-sun-01`. لا مسافات ولا عربية |
| `name_ar` | ✔ | اسم المنتج المعروض |
| `name_en` |  | للاستخدام المستقبلي (محركات البحث/الإنجليزية) |
| `price` | ✔ | بالريال، **شامل الضريبة** |
| `compare_at` |  | السعر قبل الخصم (اتركه فارغاً إن لم يوجد خصم) |
| `stock` | ✔ | الكمية الافتتاحية لكل متغير |
| `color_ar` / `color_en` | ✔ | لون المتغير؛ `color_en` يُستخدم لبناء `variant_key` |
| `image` | ✔ | مسار الصورة داخل `public`، مثال `/products/real/aura-sun-01.jpg` |
| `description` |  | الوصف |
| `status` |  | `active` (نشط) أو `draft` (مسودة لا تظهر في المتجر) |
| `featured` |  | `true` لإبراز المنتج أولاً في الشبكة |

### سلوك إعادة التشغيل آمن
- المنتج الموجود (نفس `slug`) → تُحدَّث أسماؤه وسعره ووصفه وحالته.
- المتغير الموجود (نفس `sku`) → يُحدَّث لونه فقط، **ولا تُمس كمية المخزون**،
  حتى لا تُطمس تعديلات لوحة التحكم `/admin`.
- الصورة المكرّرة لا تُضاف مرتين.

## 2) الطريقة اليدوية: ملف SQL

```bash
python scripts/import_products.py --sql        # يولّد db/005_real_products.sql
psql "$DATABASE_URL" -f db/005_real_products.sql
```

الملف الناتج قابل لإعادة التنفيذ (`ON CONFLICT`)، لذا لا تُنشئ صفوفاً مكرّرة.

## 3) صورة منتج جديدة (صور PDF الحالية)

```bash
python -m pip install pymupdf pillow
python scripts/extract_pdf_images.py --pdf "اسم الملف.pdf"
python scripts/build_products_csv.py
python scripts/import_products.py
```

- `extract_pdf_images.py`: يستخرج كل صورة من PDF، يضغطها إلى عرض 760px
  في `public/products/real/`، ويكتب تقريراً في `scripts/extracted-images.json`.
- `build_products_csv.py`: يبني CSV كاملاً من الصور (اسم + سعر مبدئي 299 ر.س +
  مخزون 10 + لون العدسة المقدَّر من الصورة). الألوان المصحّحة يدوياً موجودة
  في `OVERRIDES` داخل السكربت.
- الصور الجديدة يجب أن تُرفع مع المشروع إلى GitHub، وإلا ظهرت مكسورة في الموقع
  (الصور ملفات ثابتة، لا تُقرأ من قاعدة البيانات — القاعدة تحفظ مسارها فقط).

## ملاحظات

- سعر المتغير (`product_variants.price`) اختياري: إن كان `NULL` يُستخدم سعر المنتج.
- تعديل المخزون اليومياً لا يحتاج CSV: من `/admin` يوجد حقل مخزون مباشر لكل منتج.
- لتغيير سعر كل منتجات المجموعة مرة واحدة:
  `UPDATE products SET base_price = 349.00 WHERE slug LIKE 'aura-sun-%';`
