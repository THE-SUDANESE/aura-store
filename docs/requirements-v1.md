# وثيقة متطلبات النظام (SRS) — الإصدار 0.2 (MVP)

**المشروع:** متجر إلكتروني لبراند **AURA** — نظارات شمسية وأزياء
**السوق المستهدف:** السعودية — واجهة عربية (RTL) مع دعم إنجليزي اختياري
**العملة والضريبة:** الريال السعودي (SAR) — الأسعار **شاملة VAT 15%**
**النطاق:** النسخة الأولى (MVP) — متجر بيع مباشر (D2C) بدون تعدد بائعين

## 2. أدوار المستخدمين والصلاحيات (User Roles)

| الدور | الوصف | أهم الصلاحيات |
|---|---|---|
| **زائر (Guest)** | بدون حساب | تصفح، بحث، فلترة، إضافة للسلة، **الشراء كزائر**، تتبع طلب برقمه، التواصل |
| **عميل مسجّل (Customer)** | أنشأ حساباً | كل ما سبق + حفظ العناوين، سجل الطلبات، حالة الطلب، إدارة بياناته |
| **مشرف محتوى (Catalog Manager)** | موظف | إدارة المنتجات، الفئات، المخزون، الصور — **بدون** وصول للطلبات أو الإعدادات |
| **مدير متجر (Store Admin)** | مسؤول المتجر | كل صلاحيات المشرف + الطلبات، العملاء، الخصومات، الشحن، الصفحات، التقارير |
| **مالك/سوبر أدمن (Owner)** | أعلى صلاحية | كل ما سبق + إعدادات المتجر، إدارة مستخدمي الإدارة، الحذف النهائي، سجلات النشاط |

**قواعد عامة:**
- الصلاحيات مبنية على الأدوار (RBAC) وتُفحص **على الخادم** في كل طلب، لا في الواجهة فقط.
- يُنشأ أول حساب Owner يدوياً (Seeding)، ولا يوجد تسجيل عام لحسابات الإدارة.
- العميل لا يرى إلا بياناته وطلباته؛ أي وصول لكائن غير مملوك له يُرجع `404`.
- تفعيل 2FA للـ Owner وStore Admin (مستحسن في MVP، إلزامي قبل الإطلاق التجاري الكامل).

## 3. الميزات الوظيفية الأساسية (Core Features — MVP)

### 3.1 الكتالوج والتصفح
1. **فئات أساسية:** نظارات شمسية / أزياء — ودعم مجموعة (Collection) كطبقة تسويقية اختيارية.
2. **منتج بمتغيرات (Variants):**
   - نظارات: لون الإطار، لون العدسة، المقاس/العرض، (اختياري: شكل الإطار).
   - أزياء: المقاس (S/M/L/XL)، اللون.
   - لكل متغير: SKU مستقل، سعر، مخزون.
3. **صفحة منتج:** معرض صور، السعر والخصم، توفّر المقاس/اللون، وصف، المواصفات، جدول مقاسات (للأزياء)، سياسة الاستبدال، منتجات مشابهة.
4. **بحث وفلترة وترتيب:** بالاسم، الفئة، السعر، اللون، المقاس، "متوفر فقط"، ترتيب (الأحدث/السعر).
5. **مخزون:** إخفاء/تعطيل المتغير غير المتوفر، ومنع البيع عند نفاد الكمية.

### 3.2 السلة والشراء
6. **سلة محفوظة** (كوكي/جلسة للزائر، وتُدمج مع الحساب عند تسجيل الدخول).
7. **الدفع (Checkout):** صفحة واحدة — بيانات الشحن والفاتورة، اختيار طريقة الشحن، ملخص التكلفة، كود خصم.
8. **طرق الدفع في MVP:** الدفع عند الاستلام (COD)، والدفع الإلكتروني عبر بوابة (بطاقة/محفظة) في حال توفرها في السوق.
9. **حساب الإجماليات على الخادم فقط:** المجموع الفرعي + الشحن + الضريبة (إن وجدت) − الخصم.
10. **إنشاء الطلب:** رقم طلب، حالة ابتدائية `PENDING`، لقطة (Snapshot) لأسعار المنتجات وقت الشراء، وربط بمخزون.
11. **منع التكرار:** حماية من الطلبات المكررة (Idempotency) عند إعادة الإرسال.

### 3.3 الحساب والطلبات
12. **تسجيل/دخول:** بريد إلكتروني + كلمة مرور، أو تسجيل دخول سريع (Google) — أحدهما إلزامي في MVP.
13. **استعادة كلمة المرور** عبر البريد.
14. **سجل الطلبات** مع الحالات: `PENDING → CONFIRMED → SHIPPED → DELIVERED` وقابلية `CANCELLED / RETURNED`.
15. **تتبع الطلب** لغير المسجلين عبر رابط فريد برقم الطلب.

### 3.4 لوحة التحكم
16. **CRUD للمنتجات والمتغيرات** مع رفع صور متعددة وتحديد الصورة الرئيسية.
17. **إدارة المخزون:** تعديل الكمية، تنبيه "مخزون منخفض" عند حد معين.
18. **إدارة الطلبات:** عرض التفاصيل، تغيير الحالة، إضافة رقم التتبع، إلغاء مع إرجاع المخزون.
19. **أكواد الخصم:** قيمة ثابتة أو نسبة، حد أدنى للطلب، صلاحية زمنية، حد استخدام، تفعيل/إيقاف.
20. **إعدادات الشحن:** مناطق/محافظات وأسعارها، شحن مجاني بعد مبلغ معين.
21. **إدارة المحتوى البسيط:** الصفحات الثابتة، بانرات الرئيسية، بيانات التواصل.

### 3.5 التواصل
22. **نموذج تواصل / اشتراك في النشرة** (حفظ في قاعدة البيانات + إشعار).

### 3.6 مخارج النطاق (Out of Scope — لا تُبنى الآن)
- تعدد البائعين (Marketplace) أو تعدد المستودعات المتقدم.
- نظام نقاط وولاء أو تسويق بالإحالة.
- مدونة/محتوى SEO موسّع، تطبيق موبايل، واجهة API عامة للشركاء.
- دفع بالتقسيط، محفظة داخلية، إرجاع آلي بمرتجعات وشحن عكسي كامل.
- تقييمات بصور من العملاء (يكفي عرض نجوم/تقييمات مُدارة يدوياً إن لزم).

## 4. المتطلبات غير الوظيفية

### 4.1 الأمان (Security)
- **المصادقة والجلسات:** كلمات المرور مُهشَّرة بـ **Argon2id** (أو bcrypt)، جلسات/رموز آمنة مع انتهاء صلاحية وتدوير، وحد أقصى لمحاولات الدخول (Rate limit) + حماية من تخمين كلمات المرور.
- **التحقق من المدخلات على الخادم:** كل مدخل يُتحقق منه بمخطط (Schema validation)، ومنع حقن SQL عبر استعلامات مُعاملة (Parameterized) أو ORM، وحماية CSRF للعمليات المتغيّرة، وCSP/XSS escaping.
- **الصلاحيات والملكية:** فحص RBAC وملكية المورد في **كل نقطة نهاية**؛ لا يُقبل سعر أو إجمالي أو `userId` من العميل.
- **حماية البيانات الحساسة:** HTTPS إلزامي، تشفير البيانات الشخصية أثناء التخزين حيث يلزم، عدم تخزين بيانات البطاقة إطلاقاً (PCI — عبر بوابة دفع مستضافة)، تسجيل الأحداث الإدارية (Audit log)، ونسخ احتياطي دوري مُختبر.
- **حدود الإساءة:** Rate limiting على تسجيل الدخول/الدفع/النماذج، CAPTCHA عند الحاجة، والتحقق من صحة الطلب ضد التلاعب بالأسعار بين السلة والدفع.

### 4.2 الأداء (Performance)
- **أهداف قابلة للقياس:** LCP < 2.5 ثانية وCLS < 0.1 على شبكة 4G متوسطة؛ استجابة صفحات الكتالوج من الخادم < 300ms (p95).
- **تقنيات التنفيذ:** صور محسّنة (WebP/AVIF + مقاسات متعددة + تحميل كسول)، ضغط وتقسيم الحِزم (Code splitting)، وتخزين مؤقت (CDN للصور والأصول، وCache للصفحات العامة غير المخصصة).
- **قاعدة البيانات:** فهارس على حقول البحث والفلترة (`slug`, `category_id`, `status`, `sku`)، ومنع استعلامات N+1 بتحميل العلاقات المطلوبة فقط، وترقيم صفحات (Pagination) إلزامي لكل القوائم.
- **تحت الحمل:** السلة والإجماليات تُحسب بكفاءة، والعمليات الحسّاسة (إنشاء الطلب) داخل Transaction واحدة لضمان الاتساق.

## 5. قرارات مُعتمدة (Baseline)

| القرار | القيمة المعتمدة |
|---|---|
| اسم البراند | **AURA** |
| العملة | **SAR** (ريال سعودي) |
| الضريبة | **VAT 15% مشمولة في السعر المعروض** — تُستخرج من الإجمالي ولا تُضاف فوقه |
| الدفع | **COD افتراضي** + بنية جاهزة لإضافة بوابة دفع إلكترونية لاحقاً (جدول `payments` ومزوّد قابل للتوسعة) |
| الشراء كزائر | **مسموح** (الطلب يقبل `user_id = NULL` مع بيانات تواصل) |
| الإرجاع | **14 يوماً** — تُدار عبر حالة `RETURNED` في الطلب (دون تعقيد شحن عكسي في MVP) |
| المخزون | **مستقل لكل Variant** |

> **الكيانات المعتمدة (التفصيل الكامل في `docs/database-schema.md`):** `User`, `Address`, `Category`, `Collection`, `Product`, `ProductVariant`, `ProductImage`, `Inventory/Cart`, `CartItem`, `Order`, `OrderItem`, `Discount`, `ShippingZone`, `Page`, `CustomerMessage`, `AuditLog`.
